# NamiTalk Release

This repository hosts **public release artifacts** for the [NamiTalk](https://github.com/TryHand-Co-Ltd) Windows desktop app.

## Download

1. Open [Releases](https://github.com/TryHand-Co-Ltd/namitalk-releases/releases).
2. Pick the latest tag `namitalk-app-v*`.
3. Download `NamiTalk-<version>-windows-x64-setup.exe`.
4. Run the installer and follow the on-screen steps.

> **Platform:** Windows x64 only at this time. macOS and Linux builds are not published here yet.
